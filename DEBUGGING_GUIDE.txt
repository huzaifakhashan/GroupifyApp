🔍 كيفية استكشاف وإصلاح مشاكل الرسائل
=====================================

🎯 المشاكل التي أصلحناها:
========================

✅ 1. مشكلة النوع (signedInUser)
   - غيرنا من: late User signedInUser
   - إلى: User? signedInUser
   - السبب: لتجنب أخطاء null-safety

✅ 2. معالجة الأخطاء
   - إضافة try-catch مع معالجة FirebaseException
   - عرض رسائل خطأ واضحة للمستخدم

✅ 3. تحسين عملية الإرسال
   - إضافة logging تفصيلي
   - انتظار قليل قبل التمرير للأسفل
   - إضافة حقل timestamp خادم و createdAt محلي

✅ 4. استقبال الرسائل
   - تحسين معالجة حالات الخطأ (error, loading, empty)
   - عرض رسائل واضحة للحالات المختلفة

🔧 الخطوات المطلوبة للإصلاح:
============================

الخطوة 1: تحديث قوانين Firestore
─────────────────────────────────
اتبع التعليمات في ملف FIRESTORE_RULES.txt

الخطوة 2: التحقق من البيانات في Firebase
──────────────────────────────────────────
1. افتح Firebase Console
2. اختر مشروعك
3. ادهب إلى Firestore Database
4. تحقق من المجموعات (Collections):
   ✓ messages
   ✓ users

الخطوة 3: اختبر الإرسال
──────────────────────
1. شغل التطبيق
2. سجل دخول
3. اكتب رسالة واضغط إرسال
4. تحقق من الـ Console للرسائل:
   🟢 "✅ تم إرسال الرسالة بنجاح"
   🔴 إذا رأيت خطأ، انسخه وابحث عن الحل

الخطوة 4: اختبر الاستقبال
─────────────────────────
1. افتح Firestore Console
2. اذهب إلى مجموعة "messages"
3. يجب أن ترى المستند الجديد

الخطوة 5: اختبر من جهازين
──────────────────────────
1. شغل التطبيق على جهازين (أو محاكي + جهاز فعلي)
2. سجل دخول بحسابات مختلفة
3. أرسل رسالة من الجهاز الأول
4. يجب أن ترى الرسالة على الجهاز الثاني تلقائياً

📊 التحقق من البيانات:
======================

البيانات الصحيحة للرسالة يجب أن تحتوي على:
┌─────────────────────────┐
│ text: "محتوى الرسالة"    │
│ sender: "email@gmail"   │
│ name: "اسم المستخدم"    │
│ userId: "uid123"        │
│ timestamp: {Date}       │
│ createdAt: 1234567890   │
└─────────────────────────┘

❌ إذا وجدت حقول ناقصة:
   تأكد من أن القيم تُرسل بشكل صحيح من الكود

🐛 الأخطاء الشائعة وحلولها:
===========================

❌ الخطأ: "PERMISSION_DENIED"
✅ الحل:
   1. تحديث قوانين Firestore
   2. تأكد من تسجيل الدخول
   3. تحقق من أن request.auth موجود

❌ الخطأ: "Cannot write unknown field"
✅ الحل:
   تأكد من أسماء الحقول (case-sensitive):
   - text (صغيرة)
   - sender (صغيرة)
   - name (صغيرة)
   - userId (camelCase)
   - timestamp (camelCase)

❌ الخطأ: "Null check operator used on a null value"
✅ الحل:
   تأكد من تنفيذ getCurrentUser() قبل الإرسال
   
❌ الخطأ: "لا توجد رسائل حتى الآن"
✅ الحل:
   1. أرسل رسالة جديدة
   2. تحقق من Firestore Console
   3. تأكد من القراءة مسموح بها

🎮 اختبر بـ Emulator (ختياري):
=============================

للاختبار السريع بدون الاتصال بـ Firebase:

1. في firebase.json أضف:
   "emulators": {
     "firestore": {
       "port": 8080
     }
   }

2. شغل: firebase emulators:start

3. في main.dart في development أضف:
   await FirebaseFirestore.instance.useFirestoreEmulator('localhost', 8080);

✅ بعد كل إصلاح:
================
1. حفظ الملفات
2. `flutter pub get` (إذا أضفت مكتبات)
3. `flutter clean && flutter pub get`
4. إعادة تشغيل التطبيق
5. تنظيف الذاكرة: `flutter pub cache repair`
