🚨 حل سريع: خطأ Permission Denied
====================================

❌ المشكلة:
"The caller does not have permission to execute the specified operation"
أو
"PERMISSION_DENIED: Missing or insufficient permissions"

✅ السبب:
قواعم أمان Firestore تمنع الوصول/القراءة/الكتابة

🔧 الحل (5 خطوات سهلة):
=========================

الخطوة 1: افتح Firebase Console
─────────────────────────────────
1. اذهب إلى https://console.firebase.google.com
2. اختر مشروعك "groupify_app"
3. انتقل إلى Firestore Database

الخطوة 2: افتح القوانين (Rules)
──────────────────────────────────
1. في الجانب الأيسر اضغط "القوانين" (Rules)
2. ستجد محرر القوانين

الخطوة 3: احذف القواعم القديمة
───────────────────────────────
اختر كل شيء (Ctrl+A) واحذفه

الخطوة 4: الصق القواعم الجديدة
───────────────────────────────
انسخ من ملف FIRESTORE_RULES_CORRECT.txt الموجود في المشروع
والصقه في محرر القوانين

الخطوة 5: انشر القوانين
────────────────────────
1. اضغط زر "نشر" (Publish)
2. انتظر 2-3 ثواني
3. ستظهر رسالة "تم نشر القوانين بنجاح"

✅ اختبر الآن:
=================

1. شغل التطبيق من جديد
2. سجل دخول
3. أرسل رسالة
4. إذا نجحت → ✅ الحل نجح!
5. إذا فشلت → تحقق من الخطوات أعلاه

📸 صور للمساعدة:
=================

إذا وجدت صعوبة في إيجاد القوانين:
1. في Firebase Console
2. اضغط على Firestore Database
3. ستجد تبويبات: البيانات (Data) و القوانين (Rules)
4. انتقل إلى القوانين

🔍 التحقق من النجاح:
====================

في Firebase Console:
1. اضغط على "Firestore Database"
2. ادهب إلى "البيانات" (Data)
3. يجب أن ترى مجموعات:
   ✓ messages (رسائل)
   ✓ users (مستخدمين)
   ✓ calls (مكالمات)

4. أضف رسالة من التطبيق
5. انتظر 1-2 ثانية
6. يجب أن ترى الرسالة تظهر تلقائياً

⚠️ تحذير أمني:
================

لا تستخدم هذه القواعم في الإنتاج (Production):

❌ البطيئة والخطرة:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;  // ❌ خطر!
    }
  }
}

✅ استخدم القواعم الآمنة المذكورة أعلاه

🆘 إذا لم يعمل:
=================

تأكد من:
1. ✓ تسجيل دخول بحسابك
2. ✓ نشر القوانين بنجاح (ظهرت رسالة تأكيد)
3. ✓ انتظار 2-3 ثواني بعد النشر
4. ✓ إعادة تشغيل التطبيق
5. ✓ تسجيل دخول من جديد

إذا ظهر خطأ جديد:
- انسخ رسالة الخطأ الكاملة
- ابحث عن الرسالة في DEBUGGING_GUIDE.txt

🎯 أمثلة خطأ شائعة:
====================

❌ "Permission denied for default"
→ القواعم لم تُحدّث بعد أو لم تُنشر

❌ "Missing 'timestamp' field"
→ التطبيق يرسل بيانات ناقصة

❌ "Collection not found"
→ المجموعة لم تُنشأ بعد (ستُنشأ تلقائياً عند أول إدراج)

✨ الخطوة التالية:
====================

بعد حل مشكلة الأذونات:
1. اختبر إرسال واستقبال الرسائل
2. اختبر من جهازين مختلفين
3. اختبر الدردشات الخاصة
4. اختبر نظام المكالمات

📞 تواصل معي:
===============

إذا لم تعمل:
1. شارك رسالة الخطأ الكاملة
2. قل لي أي خطوة فشلت
3. سأساعدك بشكل مباشر
