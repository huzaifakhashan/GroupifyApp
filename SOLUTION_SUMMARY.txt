🚀 خطوات تشغيل التطبيق:
=======================

الخطوة 1: تحديث قوانين Firestore
────────────────────────────────
نسخ من FIRESTORE_RULES.txt وضعها في Firebase Console

الخطوة 2: تحديث الكود
──────────────────
تم بالفعل ✅

الخطوة 3: اختبار الرسائل
───────────────────────
1. افتح التطبيق
2. سجل دخول
3. اكتب رسالة واضغط إرسال
4. تحقق من:
   ✓ Console لرسائل النجاح
   ✓ Firestore للبيانات المحفوظة
   ✓ التطبيق لظهور الرسائل

📊 البيانات المتوقعة:
======================

في Firestore مجموعة messages:
{
  "text": "مرحبا",
  "sender": "user@example.com",
  "name": "اسم المستخدم",
  "userId": "uid123456",
  "timestamp": Timestamp(2024-01-01, 12:30:45),
  "createdAt": 1704110445000
}

🔐 التحقق من الأذونات:
======================

في Firestore Console:
1. انتقل إلى "القوانين" (Rules)
2. تأكد من:
   ✓ allow read: if request.auth != null;
   ✓ allow write: if request.auth != null;

❌ عدم السماح بـ Anonymous Access!

📱 اختبار من جهازين:
====================

الخطوة 1: التطبيق الأول
1. سجل دخول بـ user1@gmail.com
2. أرسل رسالة "مرحبا من الجهاز الأول"
3. تحقق من Firestore

الخطوة 2: التطبيق الثاني (محاكي آخر أو جهاز حقيقي)
1. سجل دخول بـ user2@gmail.com
2. يجب أن ترى الرسالة من الجهاز الأول تلقائياً
3. أرسل رسالة رد

الخطوة 3: التحقق
1. يجب أن ترى الرسالة الجديدة على الجهاز الأول تلقائياً

🐛 استكشاف الأخطاء:
====================

في VS Code افتح Terminal وشغل:
```
flutter logs
```

ستظهر الرسائل:
✅ "✅ تم إرسال الرسالة بنجاح"
❌ "❌ خطأ في إرسال الرسالة: ..."

انسخ الخطأ وتحقق من:
1. هل الرسالة تحتوي على جميع الحقول؟
2. هل المستخدم مسجل دخول؟
3. هل قواعم الأمان تسمح بالكتابة؟

⚡ تسريع الاختبار:
==================

في Firebase Console:
1. انتقل إلى Firestore
2. مجموعة messages
3. أضف مستند يدويّاً:
{
  "text": "رسالة اختبار",
  "sender": "test@gmail.com",
  "name": "اختبار",
  "userId": "test123",
  "timestamp": الآن
}

ستظهر الرسالة في التطبيق مباشرة

✅ إذا ظهرت الرسالة:
- يعني الاستقبال يعمل ✓

✅ إذا أرسلت رسالة من التطبيق وظهرت في Firestore:
- يعني الإرسال يعمل ✓

❓ أسئلة شائعة:
=================

س: الرسائل تُرسل لكن لا تظهر؟
ج: تأكد من:
   1. timestamp محفوظ بشكل صحيح
   2. قواعم الأمان تسمح بالقراءة
   3. StreamBuilder يعمل بدون أخطاء

س: لا يمكن الإرسال على الإطلاق؟
ج: تحقق من:
   1. قواعم الأمان تسمح بالكتابة
   2. المستخدم مسجل دخول
   3. الرسالة لا تكون فارغة

س: الأخطاء لا تظهر في التطبيق؟
ج: افتح Flutter Logs لرؤية جميع الرسائل

س: كيف أختبر بدون Firestore الحقيقي؟
ج: استخدم Firestore Emulator
   انظر DEBUGGING_GUIDE.txt
